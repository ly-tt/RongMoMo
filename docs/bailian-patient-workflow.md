# 百炼患者生成工作流配置

应用：`needle-generate-patient`

## 大模型节点

- 模型：使用当前可用的通义千问 Plus 或同等级文本模型
- Temperature：`0.9`
- Top P：保持默认；先只调整 Temperature
- 记忆：关闭
- 失败时重试：开启，最多 1 次
- 结果返回：开启

### 系统提示词

```text
你是《一针见血？》游戏的患者生成引擎。

必须认真执行用户提示词中的随机令牌、禁用姓名、年龄范围和性格方向。
每次调用都生成一名全新患者，不能复用固定人物模板。
姓名不能使用用户提示词列出的禁用姓名。
年龄必须位于用户提示词指定的年龄范围内，并避开指定年龄。
耐痛程度和血管难度应有明显差异，不要长期固定为相同数字。

只返回合法 JSON，不要 Markdown，不要解释，不要代码块。
字段必须为：
name：2～4 个简体中文字符
age：18～60 的整数
painTolerance：0～100 的整数
vascularDifficulty：0～100 的整数
personality：简短的中文性格描述
openingDialog：一句符合患者性格的简体中文开场对白

不得在提示词中内置或复用任何完整的固定患者 JSON 示例。
```

### 用户提示词

删除固定文本，通过输入 `/` 插入开始节点的 `query` 变量。输入框中应该显示变量标签，而不是手动输入 `query` 这几个字符。

## 结束节点

- 输出模式：文本模板
- 内容：通过 `/` 插入大模型节点的 `result`
- 流式输出：关闭

## 发布前测试

分别使用下面两段输入测试，姓名、年龄和性格都应该明显不同：

```text
禁用姓名：阿哲、小王。年龄限定18～25岁，性格方向：紧张谨慎。
```

```text
禁用姓名：阿哲、小王。年龄限定46～60岁，性格方向：幽默乐观。
```

保存后必须重新发布应用，API 才会使用新版本。
